# Slice C candidate holdout — authorship and freeze ledger

**Status: UNFROZEN / SINGLE-AUTHOR DRAFT. No inference permitted.**

- Protocol: [docs/nli-holdout-protocol.md](../../docs/nli-holdout-protocol.md), merged in `b8ae760e02aae19605f84e7e017c25cadce11fe5`.
- Source baseline: `nli_deberta_qualification_v2.json` (30 previously observed synthetic cases).
- Candidate: `holdout_cases_candidate.json` (90 authored fictional medical-text pairs, three expected labels × ten categories × three pairs).
- **Authorship:** generated by an AI assistant under user direction, without independent human annotation. Not independently annotated, not blinded, and not scientifically independent merely because examples differ.
- **Provenance:** category-driven synthetic text authored for this candidate PR. No patient records or protected health information were used.
- **Known prior evidence:** authorship followed inspection of the original 30-case manifest and knowledge of its three observed discrepancies. Category selection was preregistered; this may introduce selection bias. The protocol's stronger independence condition remains **unmet pending independent review**.
- **Static checks:** `python research/holdout/audit_candidate.py` verifies counts, label/status mapping, category balance, exact normalized pair duplicates, and flags high-similarity pairs against the baseline using SequenceMatcher >= 0.92. This heuristic does not establish semantic independence. Tests include intentionally corrupted candidates.
- **Digest:** the candidate intentionally contains `PENDING_FREEZE_AFTER_REVIEW` rather than a valid manifest digest, so the existing qualification runner cannot load or execute it as a qualification manifest.
- **Sampling dependence:** 90 premise/hypothesis pairs are constructed from only 30 distinct premises (three hypotheses per premise). Results are correlated within each premise; a 90-case binomial interval may overstate effective independence. Report premise-clustered sensitivity analyses and do not present the 90 cases as 90 independent clinical scenarios.
- **Critical cases:** ten contradiction cases are provisionally flagged critical; the criticality classification requires reviewer confirmation.

## Mandatory review and freeze checklist

1. Two independent qualified reviewers annotate all 90 expected labels and decisions, blinded to model predictions, and preserve reviewer-specific judgments. If unavailable, disclose single-annotator status and do not claim independent annotation.
2. Adjudicate all label disagreements, ambiguous temporal/negation claims, potentially underspecified statements, and category applicability before freeze. Preserve changes and rationale.
3. Inspect near-duplicate report and manually review semantic overlap both against the baseline and within the holdout; automated string similarity is insufficient.
4. Confirm the fixed model revision and decision thresholds, and establish whether existing qualification metrics and gate semantics can represent the preregistered primary false-PASS gate. **Do not interpret a legacy qualification PASS as proof that the Slice C primary gates passed.**
5. Only after independent review, generate a separate, digest-bound immutable manifest with a new benchmark version, document reviewer sign-off and exact SHA-256, and obtain separate authorization for real-model execution.
6. Publish measured results only after original artifact verification and independent metric recomputation.

**No model execution, AWS deployment, clinical use, or patient-care authorization is part of this PR.**
